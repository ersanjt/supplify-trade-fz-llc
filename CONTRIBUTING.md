# Contributing

Thanks for contributing to the Supplify Trade website.

## Guidelines

- keep changes focused and easy to review
- preserve accessibility and responsive behavior
- document visible UI changes with screenshots
- avoid committing generated deployment archives
- never commit credentials, customer information, or production server data

## Pull requests

Describe:

1. what changed
2. why it changed
3. how it was tested
4. whether deployment behavior is affected

For security issues, follow [SECURITY.md](SECURITY.md) instead of opening a public issue.
